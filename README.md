# MN690 — IoT Anomaly Detection System

ML-powered anomaly detection for APM's IoT devices.

## Models
- Isolation Forest + Local Outlier Factor (ensemble)

## Dataset
IoT-23 — 173,114 network flows across 23 real IoT device captures

## Tools
Python · Pandas · Scikit-learn · Matplotlib · Streamlit · Plotly · VS Code

## Results
- 71,776 anomalies detected
- Live Streamlit dashboard with NDB compliance export
